- **next-best-practices** - Best practices and patterns for Next.js including:
  - Parallel routes
  - Suspense boundaries
  - Data fetching patterns
  - Bundling optimization
  - Hydration error handling
  - Font optimization
  - Debugging techniques
  - Error handling patterns
  - Route handlers
  - RSC (React Server Components) boundaries
  - File conventions
  - Metadata configuration
  - Script optimization
  - Runtime selection
  - Image optimization
  - Async patterns

- **next-cache-components** - Next.js caching strategies for components

- **next-upgrade** - Guidance on upgrading to newer versions of Next.js
